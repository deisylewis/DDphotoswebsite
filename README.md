# D&D Photos - Wedding Photography Website

A beautiful, responsive wedding photography website for D&D Photos, a Lexington, Kentucky-based wedding photographer.

## Features

- **Responsive Design**: Mobile-friendly layout that works on all devices
- **Modern UI**: Clean, professional design with smooth animations
- **Contact Form**: Interactive contact form for client inquiries
- **Package Showcase**: Clear presentation of photography packages and pricing
- **Smooth Scrolling**: Enhanced user experience with smooth navigation
- **Professional Branding**: Custom logo and consistent brand identity

## Sections

1. **Hero Section**: Eye-catching introduction with call-to-action
2. **Why Section**: Unique value proposition
3. **About**: Personal introduction and photographer bio
4. **Packages**: Three-tier pricing structure (Silver, Gold, Diamond)
5. **Features**: What's included in all packages
6. **Contact**: Contact form and business information
7. **Footer**: Copyright and legal information

## Technical Details

- **HTML5**: Semantic markup for accessibility
- **CSS3**: Modern styling with Flexbox and Grid layouts
- **JavaScript**: Interactive features and form handling
- **Responsive**: Mobile-first design approach
- **Performance**: Optimized for fast loading

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. The website is ready to use!

## Customization

The website is designed to be easily customizable:
- Update contact information in the contact section
- Modify package pricing and features
- Replace placeholder images with actual photography work
- Adjust colors and styling in the CSS
